# 时记 · 个人加班与工资面板 v4

同一个人使用同一邮箱、三套独立密码，选择管理 / 编辑 / 查看状态登录。无论状态高低，只能查看本人数据。可在手机、电脑访问，数据及图片存于云端。

- 多公司：登录后选公司、随时切换；登记时必选所属公司。root 添加或重命名本人公司。
- 数据面板（默认首页）：本月加班比例、时长、加班费、预计实发、每日加班月历和工资明细。
- 记录数据：加班登记、计薪类型、工作内容。
- 加班记录 → 导出：每张最多 20MB 的图片附件、CSV 和带图片离线 HTML，均标明公司。
- 账号设置：管理状态设置本人三种状态的密码。
- 操作日志：仅本人 root 状态可查看。
- 工资参数：按月配置月薪、加班基数、个人五险一金及累计个税参数。

**开始配置请读 [DEPLOY.md](DEPLOY.md)。计算口径见 [CALCULATION.md](CALCULATION.md)。**

新 Supabase 项目只运行 `install.sql` 一次，不要同时运行历史迁移文件；已有 v3 项目运行 `migration-v4.sql` 并更新前端。更早版本按 DEPLOY.md 顺序升级。

可以部署到 GitHub Pages、其他静态服务器或 Docker。前端不依赖 GitHub；后端仍需 Supabase（认证、数据库、私有存储、Edge Functions），不是完全离线版。记录不会存入浏览器 localStorage；页面刷新后需重新登录。

当前代码未绑定真实 Supabase 项目，也未上线。工资设置需根据本人实际填写，云端隔离与同步仍需上线前按部署文档验收。
